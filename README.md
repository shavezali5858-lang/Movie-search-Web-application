# 🎬 Movie Search App

A modern and responsive movie search web application built with **React.js** that allows users to search for movies and view detailed information using the TMDB API.

## 🚀 Features

- 🔍 Search movies by title
- 🎥 Browse trending movies
- ⭐ View movie ratings
- 📅 Release date
- 📝 Movie overview
- 🖼️ High-quality movie posters
- 📱 Fully responsive design

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Axios
- TMDB API
- React Router DOM

## 📦 Installation

```bash
git clone https://github.com/your-username/movie-search-app.git
cd movie-search-app
npm install
npm run dev
```
